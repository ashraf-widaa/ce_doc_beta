The optional `scripts/docs/capture_browser_examples.cjs` reproduces the Expert
Diabetes factual capture using real interactions. It needs Playwright and Chromium
installed separately and is not run by Sphinx or RTD. Run it with a scratch output
directory; check its text/manifest against the accompanying prose before replacing
any asset. `CE_CHROMIUM_EXECUTABLE` can select an installed browser. The managed
review environment's proxy required `CE_BROWSER_IGNORE_TLS_ERRORS=1`; normal
capture environments should leave that disabled and use valid certificate trust.

The focused image is an actual element screenshot, not edited or fabricated
pixels. The full factual capture remains available as a download. No user uploads,
login credentials, local storage or session-state files are included.
