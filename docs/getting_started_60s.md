# Choose your first example

This is a short selector for readers following an older link. The current
{doc}`Quick Start <get-started/index>` introduces the workflow, tasks, modes and
capabilities with a figure before you choose an example.

## 1. Model compatibility

For Python setup and supported estimator interfaces, use
{doc}`Installation <get-started/installation>` and
{doc}`Quick API <get-started/quick_api>`. You can instead use the browser routes
in each example without installing CE.

## 2. Calibration split

CE needs separate labelled calibration examples. The shared
{doc}`data-role page <foundations/concepts/predictive_tasks>` explains fitting,
calibration and held-out evaluation; keep those roles distinct.

## 3. Choose mode

- A category: {doc}`classification <get-started/example-classification>` (binary or multiclass).
- A numerical value and interval: {doc}`interval regression <get-started/example-interval>`.
- The probability of an event on a numerical target: {doc}`event-probability regression <get-started/example-event>`.

Each page offers browser and local routes and explains the quantity being reported.
{doc}`Guarded explanations <get-started/quickstart_guarded>` are an optional support-filtering
capability, not another predictive task or output mode.

## 4. Minimal flow

For a complete runnable Python workflow with expected output and interpretation,
follow {doc}`First explanation in Python <get-started/first-python-explanation>`.
For exact range meanings and conditions, use the shared
{doc}`semantics reference <foundations/concepts/calibrated_interval_semantics>`.
