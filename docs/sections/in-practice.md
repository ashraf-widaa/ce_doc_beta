# CE in Practice

Start here to run an example and connect the result to your own task.
Choose one route; you do not need to complete every tutorial.

**For a first example, start with {doc}`Quickstart <../get-started/index>`.**

- **Predict a category:** {doc}`classification quickstart <../get-started/quickstart_classification>`.
- **Predict a numeric target or ask about a threshold:** {doc}`regression quickstart <../get-started/quickstart_regression>`.
- **Read your results:** the shared {doc}`interpretation guide <../foundations/how-to/interpret_explanations>`.
- **Connect your existing workflow:** {doc}`model and pipeline integration <../foundations/how-to/integrate_with_pipelines>`.
- **Explore advanced practical guidance:** {doc}`practitioner hub <../practitioner/index>`.

After an ordinary example, try {doc}`guarded explanations <../get-started/quickstart_guarded>`
if that filtering is relevant to your task. Method-specific limits are in
{doc}`calibrated interval semantics <../foundations/concepts/calibrated_interval_semantics>`.
For exact calls and configuration, use {doc}`CE Software & Integration <software-integration>`.
