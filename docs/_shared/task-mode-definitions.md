<p class="ce-figure-heading">Task, mode and capability: three words the docs use</p>
<div class="ce-definition-row"><strong class="ce-concept-label ce-concept-task">Task</strong><div><strong>What the model predicts.</strong><p>Classification (for example, a flower's species) or regression (for example, a housing value). Fixed when you choose the estimator and the target.</p></div></div>
<div class="ce-definition-row"><strong class="ce-concept-label ce-concept-mode">Mode</strong><div><strong>The question you ask, and the shape of the answer.</strong><p>Classification probabilities, interval regression, or thresholded (probabilistic) regression. The same regressor can serve two modes, depending on the call: <code>threshold=</code> selects the event question.</p></div></div>
<div class="ce-definition-row"><strong class="ce-concept-label ce-concept-capability">Capability</strong><div><strong>An operation you request from the calibrated wrapper.</strong><p>Predict with uncertainty, explain factually, explore alternatives; optionally add conjunctions, filter alternatives, guard explanations, or flag predictions for review (rejection).</p></div></div>
<figcaption>The <a href="../../tasks/capabilities.html">capabilities manifest</a> groups capabilities by mode and notes that semantics are mode-specific: a bound means something different in each mode.</figcaption>
</figure>
